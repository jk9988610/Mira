# 圆的化身 — 系统设计文档

> 模拟神圣罗马帝国诸家族并立：无国王、无外敌，只有家族之间的纷争与压力。

## 一、核心概念

| 概念 | 说明 |
|------|------|
| **圆** | 可移动实体，有质量、饱食、知识、快乐、健康 |
| **族长** | 每家族成年雄性中选举产生，发布订单，不参与化身工作 |
| **化身者** | 本族成年圆，可接食物/知识/快乐服务订单 |
| **保卫者** | 本族**成年男性**圆，可接堡垒防御订单并化身为堡垒 |
| **光环** | 圆形范围内的资源或战斗效果 |
| **压力** | 每个圆释放的压力 **= 其质量**；隐藏辐射，无视觉表现 |

## 二、订单系统

### 发布规则
- 族长根据周围（`CHIEF_SURVEY_RADIUS`）成员状况发单
- 冷却 1 秒；同时仅一个活跃订单
- 订单写明 **需求类型**（非指标百分比）：
  - 食物服务 / 知识服务 / 快乐服务 / **堡垒防御**

### 堡垒订单（新增）
- **触发**：族内成员感受到来自**敌族圆**的压力（`hostilePressureFelt` 超阈值）
- **接单者**：仅本族已登记保卫者的**成年男性**
- **履约**：保卫者前往坐标 → 化身为堡垒（8 秒，与农场等相同）→ 订单完成

### 资源服务订单
- **触发**：周围成员食物/知识/快乐需求不足
- **接单者**：本族化身者
- **履约**：前往坐标 → 展开临时光环服务 → 服务结束即完成

### 完成条件
到达指定坐标并开启服务（光环或堡垒化身）后，服务完成即标记 `fulfilled`。

## 三、压力与敌视

- 每个圆释放压力 = **该圆质量**
- 家族压力总计 = 所有成员质量之和
- 家族压力总计 **≥ 阈值** → 被其他家族族长视为敌人
- 家族压力总计 **< 阈值** → 取消敌视状态
- 成员属性面板显示：总压力感受、敌族压力感受

## 四、堡垒光环

- 堡垒化身 8 秒，周期性展开战斗光环
- 己族成员：获得护甲
- 敌族成员：受到质量伤害（质量归零死亡）

## 六、操控

### 键盘
| 键 | 功能 |
|----|------|
| Q | 农场 |
| Z | 校园 |
| X | 乐园 |
| C | 堡垒（需保卫者） |
| E | 生产 |
| `[` / `]` | 视角 ← / → |
| V | 回到自己视角 |

### 虚拟手柄 / Xbox 布局
| 键 | 功能 |
|----|------|
| A | 农场 |
| B | 校园 |
| X | 乐园 |
| Y | 堡垒 |
| LB | 视角 ← |
| RB | 视角 → |
| LB + RB | 回到自己视角 |

观察他人视角时不可操控移动或化身。
