# 圆的化身 — 系统设计文档

> 模拟神圣罗马帝国诸家族并立：无国王、无外敌，只有家族之间的纷争与压力。  
> 玩家以**无形体观察者**身份俯瞰世界，摇杆平移视角窗口。

## 一、核心概念

| 概念 | 说明 |
|------|------|
| **圆** | 可移动实体，有质量、饱食、知识、快乐、健康 |
| **族长** | 每家族成年雄性中选举产生，巡检成员并发布订单，不参与化身工作 |
| **化身者** | 本族成年圆，按类型注册：农场 / 校园 / 乐园 / 堡垒 |
| **光环** | 圆形范围内的资源或战斗效果 |
| **压力** | 每个圆释放的压力 **= 其质量**；隐藏辐射，无视觉表现 |
| **观察者** | 玩家无实体，摇杆仅平移视角；统计界面打开时游戏暂停 |

## 二、化身者注册

- 农场 / 校园 / 乐园 / 堡垒 **各自独立注册**，条件为**成年**（族长除外）
- 成年圆周期性掷骰入册
- **堡垒化身者**：本族成年圆均可注册，**不限性别**
- 族长巡检发现某类需求或订单无人可接时，会**提高该类型入册概率**

## 三、订单系统

### 经济

| 项目 | 数值 |
|------|------|
| 初始资金 | 90 |
| 发单成本 | 14 |
| 履约赏金 | 28 |
| 家族实收 | 100%（净收益 +14/单） |

### 发布规则

- 族长按**成员清单巡检**，逐个检查资源需求后重建清单
- 冷却 1 秒；同时仅一个活跃订单
- 需求类型：食物服务 / 知识服务 / 快乐服务 / 堡垒防御

### 履约

- 接单者须为**对应类型的已注册化身者**
- 抵达坐标 → 展开临时光环服务（5 秒）→ 服务结束即 `fulfilled`
- 堡垒订单同样以临时光环履约，不冻结为永久建筑

## 四、压力与敌视

- 每个圆释放压力 = **该圆质量**
- 家族总质量超阈值 → 被他族敌视
- 成员感受到敌族压力超阈值 → 族长发布堡垒订单

## 五、统计界面

点击「统计」或打开统计后：

- **游戏暂停**，全屏聚焦统计面板
- **三页**：化身者统计 / 订单统计 / 家族族谱
- **LB / RB** 切换页面；摇杆 / 滚轮上下滚动当前页
- **Esc / B** 关闭统计并恢复模拟

统计页面下输入**不移动地图视角**。

## 六、操控

### 观察模式（默认）

| 输入 | 功能 |
|------|------|
| 左摇杆 / WASD / 方向键 | 平移视角窗口 |
| 统计按钮 / 触屏 | 打开全屏统计（暂停） |
| P / Start | 系统暂停菜单 |

### 统计模式

| 输入 | 功能 |
|------|------|
| LB / RB / `[` `]` | 切换统计页 |
| 摇杆上下 / 滚轮 | 滚动当前页 |
| Esc / B | 关闭统计 |

虚拟手柄仅保留：**摇杆 + LB + RB**（已移除 A/B/X/Y）。

## 七、家族族谱

- 记录所有在世与**已故**成员
- 已故成员在族谱中标记「已故」
- 各家族活跃化身者人数汇总于统计页
