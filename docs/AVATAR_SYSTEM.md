# 圆的化身 — 系统设计文档

> 模拟神圣罗马帝国诸家族并立：无国王、无外敌，只有家族之间的纷争与压力。  
> 玩家以**无形体观察者**身份俯瞰世界，**触屏拖拽**平移视角窗口。

## 一、核心概念

| 概念 | 说明 |
|------|------|
| **圆** | 可移动实体，有质量、饱食、知识、快乐、健康、寿命 |
| **族长** | 每家族成年雄性中**年长者优先**选举产生的头衔；行为与其他成年圆完全相同 |
| **化身者** | 本族成年圆，按类型注册：农场 / 校园 / 乐园 / 堡垒 |
| **光环** | 圆形范围内的资源或战斗效果 |
| **压力** | 每个圆释放的压力与质量相关，可被饱食/快乐/交配降低；HUD 显示摘要 |
| **观察者** | 玩家无实体，触屏拖拽平移视角；统计界面打开时游戏暂停 |

## 二、命名与家族

- 创始：**4 个家族**，每族 **1 男 1 女**（共 8 圆）
- **姓氏**：一个大写辅音 + 一至两个小写元音（如 `Ka`、`Keo`）；同族男女共用
- **名字**：一个大写辅音 + 一至两个小写元音（如 `Bi`、`Lea`）
- **全名格式**：`姓氏 名字`（姓氏在前，中间空格）
- 创始圆配有虚构**父母姓名**（属性面板显示）
- 家族名：`{姓氏}家族`
- 每个家族有**固定家族色**，成员（含后代与妻子迁入者）共用该配色
- **夫妻**：雄性首次交配对象成为妻子；妻子**脱离原家族**迁入丈夫家族，改用夫姓与家族色
- **后代**：随父姓，名字随机；归属**父亲家族**；继承家族色

## 三、化身者注册

- 农场 / 校园 / 乐园 / 堡垒 **各自独立注册**，条件为**成年**（族长亦可注册与履约）
- 成年圆周期性掷骰入册
- **堡垒化身者**：本族成年圆均可注册，**不限性别**
- 某类订单无人可接时，会**提高该类型入册概率**

## 四、订单系统

### 经济

| 项目 | 数值 |
|------|------|
| 初始资金 | 90 |
| 发单成本 | 14 |
| 履约赏金 | 28 |
| 家族实收 | 100%（净收益 +14/单） |

### 发布规则

- **成年圆根据自身需求自发单**（饱食/知识/快乐缺口或敌族压力），发单坐标为自身位置
- 冷却 1 秒；每圆同时最多 1 个活跃单；每族最多 **2** 个活跃订单（待接/进行中）
- 需求类型：食物服务 / 知识服务 / 快乐服务 / 堡垒防御
- **无截止时限**；统计页显示下单地址、排队位次、已等时间、是否接单、接单人坐标、距目标距离与预计到达时间

### 履约

- 接单者须为**对应类型的已注册化身者**
- 抵达坐标 → 展开临时光环服务（5 秒）→ 服务结束即 `fulfilled`
- 堡垒订单同样以临时光环履约，不冻结为永久建筑

## 五、压力与敌视

- 基础释放量 ∝ **质量**
- **减压**：饱食越高、快乐越高、正在交配或交配后冷却期内，释放压力越低
- 家族总释放量超阈值 → 被他族敌视
- 成员感受到敌族压力超阈值 → 自发堡垒订单

### HUD 压力行含义

| 字段 | 含义 |
|------|------|
| **均** | 所有活跃圆感受到的**平均压力**（来自他族辐射的总和） |
| **敌压峰** | 当前**单圆感受到的敌族压力最大值** |
| **敌对族** | 因家族总压力过高而被他族标记为敌对的**关系对数**（有向计数） |

## 六、统计界面

点击「统计」后：

- **游戏暂停**，全屏聚焦统计面板
- **三页**：化身者统计 / 订单统计 / 家族族谱
- **点击页签**切换页面；**上下滑动**滚动当前页
- **右上角「关闭」**或 Esc/B 关闭统计并恢复模拟

左上角 HUD **按行分行**显示各家族活跃化身者。

## 七、操控

### 观察模式（默认）

| 输入 | 功能 |
|------|------|
| 触屏拖拽 | 平移视角窗口 |
| WASD / 方向键 / 手柄摇杆 | 平移视角（辅助） |
| 右上角「统计」 | 打开全屏统计（暂停） |
| P / Start | 系统暂停菜单 |

### 统计模式

| 输入 | 功能 |
|------|------|
| 点击页签 | 切换统计页 |
| 上下滑动 / 滚轮 | 滚动当前页 |
| 右上角「关闭」/ Esc / B | 关闭统计 |

## 八、资源地块

- 地图划分为 **12×7** 格子
- 食物 / 知识 / 快乐地块在**空格**中长出，每种维持固定数量
- 地块持续 **99 秒**后消失，并在其他空格重生
- 圆站在地块内可持续获得对应属性

## 九、圆的日程安排

每个圆按 **100 秒**为一轮日程循环（`SCHEDULE_DAY_SEC`），各圆有随机相位偏移，因此不会同时做同一件事。

### 成年圆默认权重

| 时段 | 权重 | 行为 |
|------|------|------|
| 睡觉 | 16% | 静止休息 |
| 觅食 | 34% | 寻找食物光环 |
| 吸收知识 | 10% | 寻找知识光环 |
| 吸收快乐 | 10% | 寻找快乐光环 |
| 等待 | 30% | 原地等待或按需求选目标 |

### 未成年圆

与成年类似，但学习与玩耍权重略高。

### 求偶意图窗口

- 每轮求偶意图持续约 **32 秒**，结束后指数退避冷却
- 求偶期间日程偏向 **56% 等待**，便于相遇
- **已婚**圆求偶意愿极大降低（约 3.5%），且只能与配偶交配

### 优先级（高 → 低）

1. **订单履约**（前往坐标 → 展开 5 秒光环 → 结束后注销化身者身份）
2. **生产/交配**（与配偶奔赴）
3. **日程时段**（睡觉 / 觅食 / 学习 / 快乐 / 等待）
4. 日程之外按**实际需求权重**（饱食、知识、快乐缺口）选目标

履约结束后化身者身份注销，圆回到日程与需求驱动的正常行程。

## 十、属性面板

- **质量 / 饱食 / 知识 / 快乐 / 健康**：统一 **当前/上限** 格式
- **寿命**：**剩余/上限**（上限默认 720 秒，随评估窗口调整）
- **目标坐标**：始终显示要前往的地点；无移动目标时显示自身位置
- **族长**：仅显示头衔标签，无额外能力限制
- 创始圆显示虚构父母姓名

## 十一、家族族谱

- 记录所有在世与**已故**成员；配偶与父母显示**姓名**（非内部 id）
- 已故成员在族谱中标记「已故」
- 「当前化身者」为**此刻持有该类型身份**的人数（履约结束后会注销）
