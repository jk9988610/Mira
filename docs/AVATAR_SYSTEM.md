# 圆的化身 — 系统设计文档

> 当前可玩模式：`game-scene.ts`（菜单「开始游戏」）

## 一、核心概念

| 概念 | 说明 |
|------|------|
| **圆** | 可移动实体，有质量、饱食、知识、快乐、健康 |
| **族长** | 每家族成年雄性中选举产生，负责根据周围需求发布订单，不参与化身工作 |
| **化身者** | 登记后可接单履约（展开临时光环服务） |
| **保卫者** | 登记后可化身为堡垒 |
| **光环** | 圆形范围内的持续或脉冲效果（资源、护甲、伤害） |
| **压力** | 每个圆产生并感受的隐藏辐射；家族人数超阈值后释放，过高则被他族敌视 |

## 二、订单系统

- **发布**：族长根据 `CHIEF_SURVEY_RADIUS` 内成员平均需求，发布单一订单（食物/知识/快乐）
- **冷却**：1 秒；同时仅一个活跃订单（`open` / `assigned`）
- **派发**：距订单坐标最近的空闲**化身者**接单
- **履约**：接单圆前往坐标，展开 5 秒临时光环（不冻结化身为建筑），完成后标记 `fulfilled`

相关文件：`family-market.ts`、`avatar-system.ts`（`updateMarketContract` / `tickOrderService`）

## 三、化身类型

| 类型 | 按键 | 登记要求 | 光环效果 |
|------|------|----------|----------|
| 农场 | Q | 无（玩家可直接化身） | 食物 |
| 校园 | Z | 无 | 知识 |
| 乐园 | X | 无 | 快乐 |
| 堡垒 | C | **保卫者** | 对敌族伤害 + 对己族护甲 |

化身持续 8 秒后解除冻结。族长不可化身。

相关文件：`avatar-system.ts`、`avatar-practitioner.ts`、`avatar-defender.ts`

## 四、堡垒光环

- 堡垒化身后周期性展开光环（与农场等相同的脉冲机制）
- **己族成员**在光环内获得 `fortressArmor`（抵御敌对堡垒伤害）
- **敌族成员**（因目标家族压力过高而被标记为敌对）在光环内受到质量伤害
- 质量降至 0 则死亡（从世界中移除）

相关文件：`fortress-ray.ts`

## 五、压力系统

- 家族活跃圆数量 > `PRESSURE_FAMILY_MEMBER_THRESHOLD`（4）时，家族开始释放压力
- 家族释放压力 ≥ `PRESSURE_FAMILY_RELEASE_THRESHOLD` 时，**其他所有家族**将其视为敌人
- 压力辐射：二次衰减、隐藏视觉（类似求偶信号，见 `pressure-field.ts`）
- 每个圆记录 `pressureFelt`（感受到的外族压力强度）

## 六、地图资源地块

功能分区矩形地块，范围即隐藏光环：

| 类型 | 颜色 | 效果 |
|------|------|------|
| 食物 | 淡绿 | 增加饱食 |
| 知识 | 淡紫 | 增加知识 |
| 快乐 | 淡蓝 | 增加快乐 |

站在地块内持续获得对应资源。

相关文件：`resource-zones.ts`

## 七、玩家 UI

- **光环提示**：HUD 显示当前视角目标所受光环（农场/校园/乐园/堡垒/地块等）
- **视角切换**：`V` 键在所有活跃圆之间切换观察视角；观察他人时不可操控移动或化身
- **订单面板**：右侧市场 HUD

## 八、繁殖与年龄

- 未成年：仅禁求偶与化身，可自由移动
- 后代出生后不再依恋母亲；产后不强制化身农场
- 一切服务供给由**市场订单**驱动，NPC 不自主化身
