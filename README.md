# Mira

2D 圆形吞噬游戏 — 支持手柄全程操控，面向安卓平板横屏。

> **当前阶段：M2+ 对局规则完善** — 竞技模式 + 圆的化身新模式

## 项目愿景

| 项目 | 说明 |
|------|------|
| **名称** | Mira |
| **目标** | 设计一款可用**手柄外设**全程操控的 App |
| **核心玩法** | 控制圆形在有限 2D 空间中移动、摄取颗粒与其他圆形，质量增长带来视野扩大与世界缩放 |
| **参考项目** | [ElecDog](https://github.com/jk9988610/elecdog)（工程习惯与 App 交付路径） |

## 功能规划

### 阶段 M0 — 菜单与输入（当前优先）

- [x] **主菜单**：开始游戏、按键绑定、设置、退出
- [x] **手柄全程可操控**：菜单焦点导航、确认、返回，无需触屏
- [x] **按键绑定页**：摇杆 / 方向键移动、A 确认、B 返回、肩键等可自定义并本地保存
- [x] **进入游戏**：从菜单进入对局（含暂停菜单与基础移动）

### 阶段 M1 — 核心对局

- [x] 玩家控制圆形在 2D 空间移动（有边界）
- [x] 环境随机刷新正多边形颗粒（三角形、正方形等）
- [x] 圆形经过颗粒时摄取，颗粒从环境消失
- [x] 摄取后玩家**质量**增加；屏幕右上角显示质量
- [x] 质量 ↔ 面积关系式（面积是表象，质量是本质，见 [物理模型](docs/OUTLINE.md#四物理模型)）

### 阶段 M2 — AI 与吞噬

- [x] AI 控制的圆形同样摄取颗粒
- [x] 较小圆 **3/4 身体**进入较大圆内时被吞噬，质量合并给大圆
- [x] 玩家质量增长 → 视野半径扩大
- [x] 质量超过阈值 → 缩放环境与其他实体（相机缩放）
- [x] **分身 / 合体**：Q 朝移动方向发射分裂（静止则水平）；多分身时以**质量中心**为相机与聚拢目标，重叠 2/3 自动合体
- [x] 质量越大移速越慢，越小越灵敏
- [x] 排行榜仅显示 TOP10；榜外玩家单独显示当前名次

## 架构方案（推荐）

### 结论：采用「单页 + 场景状态机」，沿用 ElecDog / RocketSimulator 的 Web → APK 路径

**不建议**使用传统多 HTML 页面（`menu.html`、`game.html` 各自跳转）。原因：

| 考量 | 多页面 HTML | 单页 + 场景状态机（推荐） |
|------|-------------|---------------------------|
| 手柄焦点 | 每页需重新绑定，易丢焦点 | 统一 `InputManager`，场景切换无刷新 |
| 游戏循环 | 页面跳转中断 `requestAnimationFrame` | 菜单 / 绑定 / 对局共享同一画布上下文 |
| APK 封装 | 可行但体验割裂 | 与 [ElecDog](https://github.com/jk9988610/elecdog) Capacitor 方案一致 |
| OTA 热更新 | 多入口难维护 | 单 `index.html` + 资源包，便于后期 OTA |

### 推荐技术栈

```
┌─────────────────────────────────────────────────────────┐
│  场景层    │ MenuScene · BindingsScene · GameScene      │
├─────────────────────────────────────────────────────────┤
│  输入层    │ InputManager（Gamepad API + 键盘 + 触屏）   │
├─────────────────────────────────────────────────────────┤
│  游戏逻辑  │ TypeScript + Canvas 2D                     │
├─────────────────────────────────────────────────────────┤
│  Web 原型  │ Vite + TypeScript → GitHub Pages           │
├─────────────────────────────────────────────────────────┤
│  APK       │ Capacitor 封装 WebView（参考 ElecDog）      │
│            │ Termux 本地 `gradle assembleDebug`          │
└─────────────────────────────────────────────────────────┘
```

### 手柄支持要点

- 使用浏览器 **Gamepad API**（`navigator.getGamepads()`），在 Android WebView / Chrome 中可用
- 菜单采用**焦点列表**（上/下/左/右切换，A 确认，B 返回），不依赖鼠标悬停
- 按键绑定页监听下一个按下的键位并写入 `localStorage`
- 对局内左摇杆 / 十字键映射为移动力；菜单与对局由 `InputManager` 按当前场景分发

## 本地开发

```bash
cd web
npm install
npm run dev
```

浏览器访问开发服务器；连接手柄后可在「按键绑定」页测试映射。

在线预览：**https://jk9988610.github.io/Mira/**

- 单局 **6 分钟**，开局 **3 秒**倒计时；本地 **20 人**竞技（静态网页，不支持联机）
- 吞噬判定：较小圆 **2/3 身体**在较大圆内（玩家分身合体同阈值）
- **Q 分身**：朝移动方向**发射**分裂（静止默认水平），最多 **16** 个
- 多分身时相机跟随**质量中心**（Σmᵢpᵢ/Σmᵢ），缩放按总质量计算
- 分身自动朝质量中心聚拢，重叠 **2/3** 自动合体；分身之间有碰撞体积
- **E 聚集**：各分身朝自身探测范围内质量最大的圆移动
- 单个分身被摄取后**永久消失**；仅当全部分身都死亡时才 3 秒后整体复活

### 其他模式 — 圆的化身

- 主菜单 → **其他模式** → **圆的化身**
- 无排行榜、无敌方 AI；仅显示个体质量与部落统计
- **Q 化身农场**：质量达标后静止 3 秒（无敌）→ 消耗质量建设固定大小农场，剩余质量返还新圆
- 农场每 3 秒在周围生成颗粒（附近颗粒达上限后暂停）
- **E 化身牧场**：更高质量阈值；牧场每 30 秒生成友方后代（圆总数超过牧场×10 时暂停）
- 农场/牧场显示为「{名字}的农场/牧场」；AI 建设后生成该 AI 而非玩家
- 排行榜仅 **TOP10**；若未上榜，榜单下方显示你的名次
- 音效由 Web Audio API **实时合成**，无需音频文件

### 安卓平板用手柄（Chrome 网页）

**不需要安装 APK**，谷歌浏览器网页即可使用手柄，但需满足：

1. 先在**系统设置 → 蓝牙**中配对手柄
2. 打开 Mira 网页后，**按手柄任意键**激活（浏览器安全策略要求）
3. 主菜单顶部会显示手柄状态（未连接 / 待激活 / 已就绪）
4. 若仍无响应，可先用触屏进入「按键绑定」检查键位

常见布局：十字键或左摇杆切换菜单，A 键确认，B 键返回。
